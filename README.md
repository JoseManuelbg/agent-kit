# Claude Code skills

Skills personales para Claude Code. Se instalan copiando (o clonando) esta carpeta en `~/.claude/skills/`.

| Skill | Uso | Qué hace |
|---|---|---|
| `lanzamiento` | `/lanzamiento [seo\|ux\|tecnico\|seguridad]` | Auditoría pre-lanzamiento de una web/API con checklists consolidados (SEO/GEO, UX, técnico/legal, seguridad) y arreglo por prioridad |
| `ui-recursos` | `/ui-recursos` | Catálogo de librerías y galerías de componentes UI para inspiración/efectos |

## Instalar en otro PC

```bash
git clone <url-del-repo> ~/.claude/skills
```

## Actualizar

Edita los `.md`, haz commit y push. Los checklists viven en `lanzamiento/checklists/`.
